YMIR: Yemeni Music Genre Classification

This repository contains selected experimental Jupyter notebooks associated with the YMIR benchmarking study for Yemeni music genre classification.

The study investigates audio feature representations and deep learning approaches for classifying five traditional Yemeni music genres: Sana'ani, Hadhrami, Lahji, Tihami, and Adeni.

Dataset

The experiments use the previously published Yemeni Music Genres Dataset (YMGD), containing 1,150 annotated audio recordings.

Dataset: https://doi.org/10.5281/zenodo.19543208

Original data publication: https://doi.org/10.1016/j.dib.2026.112859

Repository Contents

The repository includes experimental notebooks related to audio feature extraction, CNN-based classification, AST, PaSST, and cross-validation.
Reproducibility Note

These notebooks are provided as supplementary research code. Some notebooks represent exploratory configurations and may require local datasets, dependencies, or additional setup. The repository should not be regarded as a complete, independently validated reproduction package for all reported benchmark results.
